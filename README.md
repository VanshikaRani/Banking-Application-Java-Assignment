# 🏦 BankingApp - Java Console Application

A simple banking system implemented in Java using object-oriented programming. This console-based application allows users to create and manage bank accounts with operations like deposit, withdraw, view account details, and update contact information.

## 📋 Features

- ✅ Create new accounts (auto-generated account numbers)
- 💰 Deposit money into an account
- 💸 Withdraw money from an account
- 🔍 View account details
- 📧 Update email and phone number
- 🚪 Exit application safely


How It Works

Upon running, you'll see a menu with the following options:

1. Create
2. Deposit
3. Withdraw
4. View
5. Update Contact
6. Exit

1. Create Account

Auto-generates a new account number starting from 1001.

Prompts for name, initial deposit, email, and phone.

2. Deposit

Enter the account number and amount to deposit.

3. Withdraw

Enter the account number and amount to withdraw.

Checks for sufficient balance.

4. View Account

Displays account number, name, balance, email, and phone.

5. Update Contact

Updates the email and phone number for the given account.

6. Exit

Closes the application.
